# Decentralized Sports Betting Platform

A decentralized sports betting platform built on Solana, featuring:
- Automated market making for sports betting
- Real-time odds updates based on liquidity pools
- Oracle integration for game results
- Liquidity provider incentives

## Features

- 🏀 Live NBA game odds
- 💰 Decentralized betting pools
- 🌊 Liquidity provision
- 🤖 Automated settlement
- 📊 Real-time statistics

## Tech Stack

- Frontend: React + Vite + TypeScript
- Smart Contracts: Rust + Anchor Framework
- Blockchain: Solana
- Oracle: Custom implementation (expandable to Pyth/Chainlink)
